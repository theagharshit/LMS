# 🎓 `src/components/student/` Directory Overview

This directory contains UI components for the Student Portal and classroom modules.

---

## 📄 Files in `src/components/student/`

- **`AITutorModal.tsx`**: Interactive AI study assistant modal offering step-by-step guidance tailored to CDC Nepal curriculum.
- **`AssignmentDetailModal.tsx`**: View for reviewing homework instructions, downloading attached materials, and submitting student solutions.
- **`ClassroomView.tsx`**: Primary Subject Classroom hub featuring Stream announcements, File Attachments (with server upload and local fallback), Notes/Modules, and Classmate roster.
- **`ProgressTrackerView.tsx`**: Visual analytics view rendering subject score charts, attendance trends, and achievement badges.
- **`QuizRunnerModal.tsx`**: Interactive online quiz modal allowing students to take CDC curriculum quizzes with instant scoring.
- **`StudentDashboard.tsx`**: Main student portal dashboard highlighting upcoming homework, streak stats, timetable, and quick AI tools.
- **`StudentProfileView.tsx`**: Student profile page showing earned badges, XP points, roll number, and contact details.
