# 🎨 `src/components/` Directory Overview

This directory contains all UI components for the **Sikshya LMS** interface, modularized by role and functionality.

---

## 📂 Subdirectories

- **[`common/`](./common/README.md)**: Navigation bars, sidebars, messaging interfaces, notifications, and shared calendar widgets.
- **[`parent/`](./parent/README.md)**: Parent portal dashboards, AI parent digests, and parental control controls.
- **[`student/`](./student/README.md)**: Student dashboards, subject classroom stream views, AI tutor modals, homework views, and quiz runners.
- **[`teacher/`](./teacher/README.md)**: Teacher grading desks, attendance registers, timetable managers, and AI quiz builder modals.
