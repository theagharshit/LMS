# ⚛️ `src/context/` Directory Overview

This directory contains global React Context abstractions for state management across the application.

---

## 📄 Files in `src/context/`

- **`AppContext.tsx`**: Central application state provider managing active user session, role switching (`student`, `teacher`, `parent`), enrolled classrooms, stream posts, homework submissions, attendance registers, messages, and weekly timetables.
