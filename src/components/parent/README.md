# 👨‍👩‍👧 `src/components/parent/` Directory Overview

This directory contains UI components for the Parent Portal.

---

## 📄 Files in `src/components/parent/`

- **`AIParentSummaryModal.tsx`**: Modal generating bilingual (English & Nepali Devanagari) weekly academic digests powered by Gemini 3.6 Flash.
- **`ParentDashboard.tsx`**: Dashboard view for parents tracking their child's attendance rate, subject grade trends, and pending homework.
- **`ParentalControlsModal.tsx`**: Modal for managing screen-time limits, AI tutor assistance toggles, and notification settings.
