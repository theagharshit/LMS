# 👨‍🏫 `src/components/teacher/` Directory Overview

This directory contains UI components for the Teacher Portal.

---

## 📄 Files in `src/components/teacher/`

- **`AttendanceRegister.tsx`**: Daily attendance marking tool for class teachers (Present, Absent, Late) with automatic percentage calculation.
- **`QuizBuilderModal.tsx`**: AI-powered quiz generator modal allowing teachers to quickly create structured CDC curriculum quizzes.
- **`TeacherDashboard.tsx`**: Main teacher portal dashboard featuring homework grading queue, struggling student alerts, timetable manager, and quick AI tools.
