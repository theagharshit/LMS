# 🛠️ `src/utils/` Directory Overview

This directory contains system utilities, logging modules, and helper functions.

---

## 📄 Files in `src/utils/`

- **`logger.ts`**: Environment-aware dual-mode logging system supporting 2 environments (`development` vs `production`) and 2 verbosity modes (`normal` / minimal vs `verbose` / `-v`). Includes Express HTTP request logging middleware.
